## Overview

Every Work Center has a Type that determines how CoCoCo treats it. The Type affects how jobs are routed, how progress is tracked, and which Workflow nodes are relevant.

## Types

| Type | Description |
|---|---|
| **Prepress** | Preparation and file processing before printing |
| **Press** | Sheet-fed, web, or digital printing machines |
| **Finishing** | Cutting, folding, binding, laminating |
| **Shipping** | Packing, dispatch, and delivery |
| **Storage** | Warehouse, stock locations |
| **Quality** | Inspection and approval stations |
| **Generic** | Any resource that doesn't fit another type |

## Choosing the right type

When in doubt, use **Generic**. You can always change the type later. The Type is mainly used for filtering and reporting — it doesn't restrict what a Work Center can actually do.
