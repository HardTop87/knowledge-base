## How to create a user

1. Go to **Identity & Access** in the left sidebar
2. Click **+ Create User** in the Users card
3. Enter:
   - **Email address** — the person's work email
   - **Full name** — displayed throughout the platform
   - **User Type** — Human, Kiosk, or Bot
4. Click **Save**

The user receives an email invitation with a link to set their password.

## User types

| Type | When to use |
|---|---|
| **Human** | Regular staff with personal login credentials |
| **Kiosk** | Shared shopfloor terminal with a simplified interface |
| **Bot** | Service account for automated processes — no login, API only |
