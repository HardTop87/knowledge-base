## What is a Network?

A Network is a logical container for your connected machines and devices. It provides the communication channel between your physical production equipment and CoCoCo.

Most operations run with a single Network. You might use multiple Networks if you have physically separate production sites or need to isolate device groups.

## How to create a Network

1. Go to **Menu → IOT → Networks** in the sidebar
2. Click **+ Add Network**
3. Enter a **Name** — something descriptive like `Main Production Floor` or `Digital Printing`
4. Optionally add a **Description**
5. Click **Save**

The Network is now ready. Next, add a Controller to manage device communication, then connect your Devices.
