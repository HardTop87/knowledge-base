## How to create an Order

### From scratch

1. Go to **Data → Commercial → Orders**
2. Click **+ New Order**
3. Select the **Customer**
4. Add **Line Items** with quantities and prices
5. Set the **Required date**
6. Click **Save as Draft**, then **Confirm** when ready

### From an Estimate

1. Open the accepted Estimate
2. Click **Convert to Order**
3. Review the pre-filled details and click **Confirm**

## Order statuses

| Status | Description |
|---|---|
| **Draft** | Being prepared |
| **Confirmed** | Ready for production |
| **In Production** | Job is active on the floor |
| **Partially Shipped** | Some items dispatched |
| **Shipped** | All items dispatched |
| **Delivered** | Customer confirmed receipt |
| **Completed** | Fully closed |
| **Cancelled** | Withdrawn |
