## What are Shift Definitions?

Shift Definitions specify when your Work Centers are operational. They define the working hours, shift names, and schedules that the platform uses for planning, reporting, and OEE calculations.

## How to set up Shift Definitions

1. Go to **Data → Shift Definitions** (under Production Setup in the System menu)
2. Click **+ Add Shift Definition**
3. Enter a **Name** (e.g. `Morning Shift`, `Night Shift`)
4. Set the **Start time** and **End time**
5. Select which **Days** this shift runs
6. Assign to one or more **Work Centers**
7. Click **Save**

## Multiple shifts

You can define multiple shifts per day per Work Center. Shifts should not overlap for the same Work Center.
