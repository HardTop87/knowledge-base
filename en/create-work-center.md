## What is a Work Center?

A Work Center is any resource in your production process that performs or supports work. This includes printing machines, finishing equipment, people, and tools.

Work Centers are the building blocks of your production structure. Jobs move through them, Workflows route to them, and Metrics are reported against them.

## How to create a Work Center

1. Go to **Data → Work Centers**
2. Click **+ Add Work Center**
3. Fill in the details:
   - **Name** — the name of the machine or resource (e.g. `HP Indigo 12000`)
   - **Type** — select the Work Center type that best fits (see [Work Center Types](#work-center-types))
   - **Production Cell** — assign it to an existing cell
4. Click **Save**

## Assigning a Device

If the Work Center corresponds to a connected machine, link the Device:

1. Open the Work Center
2. Go to the **Device** tab
3. Select the Device from the list
4. Save
