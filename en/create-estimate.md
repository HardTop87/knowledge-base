## How to create an Estimate

1. Go to **Data → Commercial → Estimates**
2. Click **+ New Estimate**
3. Select the **Customer**
4. Add **Line Items** — products with quantities and unit prices
5. Set the **Valid until** date
6. Click **Save as Draft**

## Sending to the customer

1. Open the Estimate
2. Review all details
3. Click **Send**

Status changes to `Sent`.

## After the customer responds

- **Accepted** → Click **Convert to Order**
- **Rejected** → Mark as rejected and optionally revise
- **Revise** → Duplicate, adjust pricing, re-send

## Estimate statuses

| Status | Description |
|---|---|
| **Draft** | Being prepared |
| **Sent** | Awaiting customer response |
| **Accepted** | Customer confirmed |
| **Rejected** | Customer declined |
| **Expired** | Valid-until date passed |
| **Revised** | Superseded by a newer version |
