## What is the API Docs page?

The API Docs page is CoCoCo's built-in reference browser for the full GraphQL API. It documents every type, query, and mutation available on your platform.

## How to open it

Go to **Menu → Developer → API Docs**, or navigate to `https://your-domain.cococo.app/#/docs`.

## What's documented

| Scope | Count |
|---|---|
| GraphQL types | 658 |
| GraphQL queries | 275 |
| GraphQL mutations | 281 |

## Using the docs

The docs are interactive — click through types to explore fields, see required arguments, and understand response structures.

For running live queries, use the [GraphQL Playground](#graphql-playground) which connects directly to the API with your credentials.
