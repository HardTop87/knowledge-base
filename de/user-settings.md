## User Settings öffnen

Klicken Sie oben rechts auf Ihr **Profilbild** und wählen Sie **User Settings** aus dem Dropdown. Oder rufen Sie direkt `https://your-domain.cococo.app/#/user-settings` auf.

## Account

Im Bereich Account sehen Sie Ihren aktuellen Namen und Ihre E-Mail-Adresse, wie sie in CoCoCo hinterlegt sind.

- **Name**: Ihr Anzeigename auf der gesamten Plattform
- **E-Mail**: Die Adresse für Login und Benachrichtigungen

Wenn Sie Name oder E-Mail ändern möchten, wenden Sie sich an Ihren CoCoCo Administrator. Diese Felder werden über den Users-Bereich in Identity & Access gepflegt, nicht in Ihren eigenen Einstellungen.

## Preferences

**Sprache**
Wählen Sie Ihre bevorzugte Oberflächensprache für CoCoCo. Im Dropdown auswählen und speichern. Die Oberfläche wird sofort aktualisiert.

## Security

**Passwort ändern**

1. Geben Sie Ihr **aktuelles Passwort** ein
2. Geben Sie das **neue Passwort** ein
3. Bestätigen Sie das neue Passwort
4. Klicken Sie auf **Save**

Wenn Sie Ihr aktuelles Passwort vergessen haben, nutzen Sie stattdessen den **Forgot password** Link auf der Login-Seite.
