## Vorschau

Während der Bearbeitung klicken Sie auf **Preview**, um eine Live-Vorschau zu öffnen. Die Vorschau läuft mit Ihren Zugangsdaten und greift auf echte Plattformdaten zu.

Nutzen Sie die Vorschau zum Testen von Interaktionen, zur Layoutprüfung und zum Verifizieren des Dark- und Light-Mode-Verhaltens.

## Veröffentlichen

Wenn die App fertig ist:

1. Klicken Sie auf **Publish**
2. Die App ist sofort für User mit Zugriff verfügbar

Veröffentlichte Apps erscheinen je nach Kind am passenden Ort:

- **Page** → linke Seitenleiste
- **Dashboard** → Dashboards-Tab-Liste
- **Kiosk** → Kiosk-Oberfläche
- **Job View** → Job-Detailbereich

## Versionshistorie

Jede Veröffentlichung erzeugt einen unveränderlichen Versionsstand. Sie können jederzeit auf eine frühere Version zurückkehren, falls etwas bricht.

[Versionshistorie und Rollback](#version-history)

## Arbeitsversion vs. veröffentlicht

Der Editor arbeitet immer auf der **Arbeitsversion**. Einem Entwurf, der für User nicht sichtbar ist, bis Sie veröffentlichen. Beim Veröffentlichen wird aus der Arbeitsversion eine neue Version erzeugt und live geschaltet.
