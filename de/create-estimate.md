## Ein Estimate anlegen

1. Wechseln Sie zu **Data → Commercial → Estimates**
2. Klicken Sie auf **+ New Estimate**
3. Wählen Sie den **Customer**
4. Fügen Sie **Line Items** ein: Produkte mit Menge und Einzelpreis
5. Setzen Sie das **Valid until** Datum
6. Klicken Sie auf **Save as Draft**

## An den Kunden senden

1. Öffnen Sie das Estimate
2. Prüfen Sie alle Angaben
3. Klicken Sie auf **Send**

Der Status wechselt auf `Sent`.

## Nach der Kundenantwort

- **Accepted** → **Convert to Order** klicken
- **Rejected** → als rejected markieren und optional überarbeiten
- **Revise** → duplizieren, Preise anpassen und erneut versenden

## Estimate-Status

| Status | Beschreibung |
|---|---|
| **Draft** | In Vorbereitung |
| **Sent** | Wartet auf Kundenantwort |
| **Accepted** | Kunde hat bestätigt |
| **Rejected** | Kunde hat abgelehnt |
| **Expired** | Gültigkeitsdatum überschritten |
| **Revised** | Durch eine neuere Version ersetzt |
