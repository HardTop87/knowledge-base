## Was ist ein Work Center?

Ein Work Center ist jede Ressource in Ihrem Produktionsprozess, die Arbeit leistet oder sie unterstützt. Das umfasst Druckmaschinen, Finishing-Ausrüstung, Mitarbeiter und Werkzeuge.

Work Centers sind die Bausteine Ihrer Produktionsstruktur. Jobs durchlaufen sie, Workflows leiten Arbeit an sie weiter und Metriken werden an ihnen gemeldet.

## Ein Work Center anlegen

1. Wechseln Sie zu **Data → Work Centers**
2. Klicken Sie auf **+ Add Work Center**
3. Füllen Sie die Felder aus:
   - **Name**: die Bezeichnung der Maschine oder Ressource (z.B. `HP Indigo 12000`)
   - **Type**: der passende Work Center Typ (siehe [Work Center Typen](#work-center-types))
   - **Production Cell**: die zugehörige Production Cell
4. Klicken Sie auf **Save**

## Ein Device zuweisen

Wenn das Work Center einer angebundenen Maschine entspricht, verknüpfen Sie das Device:

1. Öffnen Sie das Work Center
2. Wechseln Sie zum Tab **Device**
3. Wählen Sie das Device aus der Liste
4. Speichern
