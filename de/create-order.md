## Einen Order anlegen

### Von Grund auf

1. Wechseln Sie zu **Data → Commercial → Orders**
2. Klicken Sie auf **+ New Order**
3. Wählen Sie den **Customer**
4. Fügen Sie **Line Items** mit Menge und Preis ein
5. Setzen Sie das **Required date**
6. Klicken Sie auf **Save as Draft** und dann auf **Confirm**, wenn alles passt

### Aus einem Estimate

1. Öffnen Sie das akzeptierte Estimate
2. Klicken Sie auf **Convert to Order**
3. Prüfen Sie die vorausgefüllten Angaben und klicken Sie auf **Confirm**

## Order-Status

| Status | Beschreibung |
|---|---|
| **Draft** | In Vorbereitung |
| **Confirmed** | Bereit für die Produktion |
| **In Production** | Job ist auf der Produktionsfläche aktiv |
| **Partially Shipped** | Teil der Ware ist versandt |
| **Shipped** | Alle Positionen sind versandt |
| **Delivered** | Empfang vom Kunden bestätigt |
| **Completed** | Vollständig abgeschlossen |
| **Cancelled** | Zurückgezogen |
