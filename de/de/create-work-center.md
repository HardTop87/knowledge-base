## Was ist ein Work Center?

Ein Work Center ist jede Ressource in deinem Produktionsprozess, die Arbeit leistet oder sie unterstützt. Das umfasst Druckmaschinen, Finishing-Ausrüstung, Mitarbeiter und Werkzeuge.

Work Centers sind die Bausteine deiner Produktionsstruktur. Jobs durchlaufen sie, Workflows leiten Arbeit an sie weiter und Metriken werden an ihnen gemeldet.

## Ein Work Center anlegen

1. Wechsle zu **Data → Work Centers**
2. Klicke auf **+ Add Work Center**
3. Fülle die Felder aus:
   - **Name**: die Bezeichnung der Maschine oder Ressource (z. B. `HP Indigo 12000`)
   - **Type**: der passende Work Center Typ (siehe [Work Center Typen](#work-center-types))
   - **Production Cell**: die zugehörige Production Cell
4. Klicke auf **Save**

## Ein Device zuweisen

Wenn das Work Center einer angebundenen Maschine entspricht, verknüpfe das Device:

1. Öffne das Work Center
2. Wechsle zum Tab **Device**
3. Wähle das Device aus der Liste
4. Speichern
