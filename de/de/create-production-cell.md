## Was ist eine Production Cell?

Eine Production Cell ist eine benannte Gruppe von Work Centers. Sie repräsentiert einen funktionalen Bereich deiner Produktionsfläche, zum Beispiel `Digitaldruck`, `Finishing` oder `Buchbinderei`.

Production Cells helfen, deine Work Centers zu organisieren und Jobs einfacher dem richtigen Bereich zuzuordnen.

## Eine Production Cell anlegen

1. Wechsle zu **Data → Production Cells** (im oberen Data-Menü)
2. Klicke auf **+ Add Production Cell**
3. Vergib einen **Name** (z. B. `Digitaldruck`)
4. Optional: **Description** ergänzen
5. Klicke auf **Save**

Nach dem Anlegen kannst du Work Centers zu dieser Cell hinzufügen.
