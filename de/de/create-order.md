## Einen Order anlegen

### Von Grund auf

1. Wechsle zu **Data → Commercial → Orders**
2. Klicke auf **+ New Order**
3. Wähle den **Customer**
4. Füge **Line Items** mit Menge und Preis ein
5. Setze das **Required date**
6. Klicke auf **Save as Draft** und dann auf **Confirm**, wenn alles passt

### Aus einem Estimate

1. Öffne das akzeptierte Estimate
2. Klicke auf **Convert to Order**
3. Prüfe die vorausgefüllten Angaben und klicke auf **Confirm**

## Order-Status

| Status | Beschreibung |
|---|---|
| **Draft** | In Vorbereitung |
| **Confirmed** | Bereit für die Produktion |
| **In Production** | Job ist auf der Produktionsfläche aktiv |
| **Partially Shipped** | Teil der Ware ist versandt |
| **Shipped** | Alle Positionen sind versandt |
| **Delivered** | Empfang vom Kunden bestätigt |
| **Completed** | Vollständig abgeschlossen |
| **Cancelled** | Zurückgezogen |
