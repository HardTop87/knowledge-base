## Was ist eine Production Cell?

Eine Production Cell ist eine benannte Gruppe von Work Centers. Sie repräsentiert einen funktionalen Bereich Ihrer Produktionsfläche, zum Beispiel `Digitaldruck`, `Finishing` oder `Buchbinderei`.

Production Cells helfen, Ihre Work Centers zu organisieren und Jobs einfacher dem richtigen Bereich zuzuordnen.

## Eine Production Cell anlegen

1. Wechseln Sie zu **Data → Production Cells** (im oberen Data-Menü)
2. Klicken Sie auf **+ Add Production Cell**
3. Vergeben Sie einen **Name** (z.B. `Digitaldruck`)
4. Optional: **Description** ergänzen
5. Klicken Sie auf **Save**

Nach dem Anlegen können Sie Work Centers zu dieser Cell hinzufügen.
