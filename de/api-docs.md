## Was ist die API-Docs-Seite?

Die API-Docs-Seite ist der eingebaute Referenzbrowser für die komplette GraphQL API von CoCoCo. Dokumentiert ist jeder Type, jede Query und jede Mutation Ihrer Plattform.

## Öffnen

Wechseln Sie zu **Menu → Developer → API Docs** oder direkt auf `https://<your-domain>/#/docs`.

## Was dokumentiert ist

| Bereich | Anzahl |
|---|---|
| GraphQL Types | 658 |
| GraphQL Queries | 275 |
| GraphQL Mutations | 281 |

## Die Dokumentation nutzen

Die Dokumentation ist interaktiv. Klicken Sie sich durch die Types, um Felder zu erkunden, Pflichtargumente zu sehen und die Response-Struktur zu verstehen.

Um Queries live auszuführen, nutzen Sie das [GraphQL Playground](#graphql-playground), das direkt mit Ihren Credentials auf die API zugreift.
