## Einen User anlegen

1. Wechseln Sie zu **Identity & Access** in der linken Seitenleiste
2. Klicken Sie auf **+ Create User** in der Users-Karte
3. Geben Sie ein:
   - **E-Mail-Adresse**: die geschäftliche E-Mail der Person
   - **Vollständiger Name**: wird auf der gesamten Plattform angezeigt
   - **User Type**: Human, Kiosk oder Bot
4. Klicken Sie auf **Save**

Der User erhält eine E-Mail-Einladung mit einem Link zum Setzen des Passworts.

## User Types

| Typ | Wann nutzen |
|---|---|
| **Human** | Reguläres Teammitglied mit persönlichen Zugangsdaten |
| **Kiosk** | Gemeinsam genutztes Shopfloor-Terminal mit vereinfachter Oberfläche |
| **Bot** | Service-Account für automatisierte Prozesse, kein Login, nur API |
